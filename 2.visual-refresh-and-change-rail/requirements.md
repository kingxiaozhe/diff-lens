## 功能需求

1. [R-001] **视觉层精修**：只动 type scale / 间距节奏 / 控件形态 / 色值微调；五段行结构与 PRD F-001~F-043 功能集**零变更**（② 结构基准，用户确认不等 Stitch 新稿）
2. [R-002] **pip 轨道**：结果区滚动条一侧显示全部改动位置的 pip，语义色绿=增 / 红=删 / 琥珀=改
3. [R-003] pip **点击跳转**到对应差异（复用现有跳转机制）；当前跳转目标 pip 以强调色标出，与行的 `.jumped` 描边同步
4. [R-004] 类型区分**不只靠颜色**：pip 悬停有 `title`（如 `changed · line 42`），并作为可聚焦控件带 `aria-label`
5. [R-005] 无差异 / 空态 / 错误态时 pip 轨道**整体隐藏**，不留视觉噪声
6. [R-006] **minor（次要差异）不打 pip**——与统计行「minor 为 0 不显示」同一淡化原则
7. [R-007] 所有新增/修改的颜色**双主题**同步给值
8. [R-008] 视图切换（Unified/Split/Inline）、折叠展开、wrap 等几何开关、**窗口 resize** 后，pip 位置与当前目标态均**正确刷新**，不残留旧位置、不丢当前态

## 非功能需求

- 性能: pip 渲染并入现有 `render()` 批次（一次 innerHTML 落地），事件委托，**禁止逐 pip 绑监听**；word wrap 等仅改几何不重渲染的开关，pip 位置需同步刷新
- 安全: 零网络、零新权限；pip 内容仅含引擎数据（类型 + 行号），不插值用户文本
- 兼容性: 900px 断点下轨道保留；裸浏览器（无 chrome API）可运行供 smoke
